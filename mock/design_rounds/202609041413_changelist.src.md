# src changelist

The source half of the fix round: the three findings that blocked the merge of
the configuration round and the ones beneath them, each fixed at its site with
the test that would have caught it.

## CHANGE: `Toml::set` FROM `a top-level key with no top-level line lands at the end of the file` TO `it lands above the first header`
File: `mock/crates/renki/src/config/toml.rs`, `mock/crates/renki/src/config/toml_tests.rs`
Verification: `grep -c 'first_header' mock/crates/renki/src/config/toml.rs` is at least 4; `cargo test -p renki a_key_not_yet_in_the_file` is green, and its body now carries a file that opens with `[model]`, one with two tables, one with a comment above the header, a comments-only file, and the control where a top-level line exists.

## CHANGE: `config set` FROM `writes into a directory that may not exist` TO `creates the directory first, through write_user`
File: `mock/crates/renki/src/config/query.rs`, `mock/crates/renki/src/config/config_tests.rs`
Verification: `grep -n 'pub(crate) fn write_user' mock/crates/renki/src/config/query.rs` returns one match and `grep -c 'std::fs::write' mock/crates/renki/src/config/query.rs` returns 1, inside it; `cargo test -p renki the_users_file_is_written_into_a_directory_that_does_not_exist_yet` is green.

## CHANGE: the published `renki` package FROM `no LICENSE, since the crate root moved and the file did not` TO `LICENSE beside the manifest, asserted by the package test`
File: `mock/crates/renki/LICENSE`, `mock/crates/renki/tests/the_readme_tells_the_truth_about_the_package.rs`
Verification: `cargo package -p renki --list --allow-dirty | grep -c '^LICENSE$'` returns 1; `cargo test -p renki --test the_readme_tells_the_truth_about_the_package the_package_ships_its_licence` is green.

## CHANGE: the module doc of `config` and the comment on `config_root` FROM `<SHORT>_CONFIG for the file, <SHORT>_CONFIG_DIR for the directory` TO `<SHORT>_CONFIG_FILE and <SHORT>_CONFIG`
File: `mock/crates/renki/src/config/mod.rs`, `mock/crates/renki/src/cache.rs`
Verification: `grep -c '_CONFIG_DIR' mock/crates/renki/src/*.rs mock/crates/renki/src/config/*.rs` is 0 in every file, and `grep -n 'CONFIG_FILE. naming' mock/crates/renki/src/config/mod.rs` returns one match.

## CHANGE: `selfupdate::reinstall` FROM `one cargo install` TO `the prerequisite check and install_with_retry, like materialise`
File: `mock/crates/renki/src/selfupdate.rs`
Verification: `grep -n 'install_with_retry\|cargo_is_on_path' mock/crates/renki/src/selfupdate.rs` returns matches inside `reinstall`, and `grep -c 'updated launcher failed' mock/crates/renki/src/selfupdate.rs` is 0.

## CHANGE: the two prerequisite checks the design names and the code lacks FROM `unmarked` TO `a FIXME on cargo_is_on_path and two ignored catalogue tests`
File: `mock/crates/renki/src/retry.rs`
Verification: `grep -c 'FIXME: the design names two more prerequisites' mock/crates/renki/src/retry.rs` is 1; `cargo test -p renki retry:: -- --list --ignored` lists `a_pinned_toolchain_rustup_lacks_is_refused_by_name_before_cargo_runs` and `an_unreachable_git_source_is_refused_by_name_before_cargo_runs`, and `cargo test -p renki retry:: -- --ignored` fails on both, which is the catalogue being red.

## CHANGE: `Cli::take` FROM `strips --cfg for every tool` TO `leaves the arguments alone for a tool with no settings`
File: `mock/crates/renki/src/config/mod.rs`, `mock/crates/renki/src/config/config_tests.rs`
Verification: `grep -n 'if tool.settings.is_empty()' mock/crates/renki/src/config/mod.rs` returns one match inside `take`; `cargo test -p renki a_tool_with_no_settings_leaves_config_to_the_engine` is green with the `--cfg` arms in it.

## CHANGE: `renki-config` FROM `no readme test, readme block compiled by nothing` TO `the readme truth test its siblings have, and the block as a doctest`
File: `mock/crates/renki-config/tests/the_readme_tells_the_truth_about_the_package.rs`, `mock/crates/renki-config/src/lib.rs`
Verification: `grep -n 'cfg_attr(doctest, doc = include_str!("../README.md"))' mock/crates/renki-config/src/lib.rs` returns one match, a crate attribute rather than a carrier type, so the design has no new name to account for; `cargo test -p renki-config --doc` lists the readme as `src/lib.rs` and is green; `cargo test -p renki-config --test the_readme_tells_the_truth_about_the_package` is green.

## CHANGE: `List<K>::from_text` FROM `accepts a quoted item holding a quote` TO `refuses it, since the canonical form cannot carry one`
File: `mock/crates/renki-config/src/kind.rs`, `mock/crates/renki-config/tests/every_contract_on_a_toy_store.rs`
Verification: `grep -n "contains('\"')" mock/crates/renki-config/src/kind.rs` returns one match inside `from_text` of `List<K>`; `cargo test -p renki-config a_list_parses_item_by_item` is green with the refused item in it.

## Not changed, and why

Six files the review counted past the `file-size` limit are under it by the
lint's own count, which is of lines neither blank nor comment; `cargo mock
--lint-only --strict` reports no `file-size` finding and that is the
measurement. The closed round's topic file names the wrong variable and stays
as it was, since a closed round is an archive.
