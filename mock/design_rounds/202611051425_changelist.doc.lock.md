# doc changelist

One section of renki's design amended and the document rendered from it. Descends from the topic file `202611051424_topic.review-fixes-for-forgetting-a-refused-build.md`, the one open topic, and is everything that topic asks of the design.

## What lands

- `mock/crates/renki/DESIGN.md.tmpl`, "A refused build forgets its resolution": the sentence "The first is not exact either" is reworded so that it names what it refers to, a refusal that is not a broken revision. A paragraph is added saying that the forget names the refused revision and removes the record only while it still names that revision, and that a build refused on the rebuild after an eviction forgets like the first build, with no exception, since the key holds the toolchain.
- `docs/`, rendered.

## Claims the source changelist will carry

- `pin::forget_resolution` takes the refused revision and removes the recorded resolution of the pin's url and branch only while it still names that revision.
- `dispatch` in `lib.rs` forgets the resolution when the rebuild after an eviction is refused, through the same path as the first build.
- `extension::place_via_scratch` is generic over the error type and the `Into<String>` bound is gone, so a `Refused` keeps its type on the scratch route.
- `cache::ensure_built` returns `NotStarted` for the unmade cache directory and for the key lock not taken, each covered by a test that fails when it returns `Refused`.
- The mutant script moves from `mock/research/202611030534_forget-resolution-mutants/` to `mock/research/sketches/forget-resolution-mutants/`, and the key assertion in `lib_tests/builds.rs` fails when the key's inputs are not wired through.
