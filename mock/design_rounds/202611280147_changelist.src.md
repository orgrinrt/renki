## Claims

- CHANGE `posix/manifest.sh` and the `awk` it runs: `dump <file>` and
  `get <file> <key>` in the dump's bytes, over the layers, the include rule,
  the order, the merge, `meta` and the predicates, refusing with file and line
  anything outside the stated TOML subset.
- CHANGE `posix/conformance/`: one directory per fixture, its manifest files
  and a `dump` or a `refused` file, a fixture for each predicate kind, `env`,
  `shell`, `not`, `all` and `any`, holding and not holding, and `env` with each
  truthy and falsy word and a refused one.
- CHANGE one test of `renki-manifest` running the POSIX reader over every
  fixture and comparing with what the fixture holds; the Rust reader's half of
  it comes with the reading.
- CHANGE `renki-manifest`'s feature is `processes`, as the design names it,
  in its manifest, its host and its tests; it takes `tomlfuse-parse` at its
  own first version, `0.0.1-rc.1`, and reads a parse's node count off the
  `Document` the parser now gives back; its package leaves out the POSIX
  reader's test, which reads `posix/` outside the crate.
- CHANGE `renki-config`: `Stack` with `Stack::new` and `Stack::layers`,
  checking every `meta.unset` against the layers below it and the shape at
  every key and every table above one by `meet`, once, answering the first
  `BadMerge` in the stack's order, by asking `stacked` every key the layers
  hold, every table above one and every key an `unset` names; `stacked` and
  `resolve` take a `Stack`, and over a checked one `stacked` refuses nothing.
- CHANGE `renki-config`: `Shape` gains `Tables` and `Empty`; `meet` appends
  two lists of values or two arrays of tables, refuses one over the other,
  and appends the empty list to either and either to it.
- CHANGE the stores that implement `Store`, the launcher's `config::toml` and
  the tests' own, answer the five shapes.
- CHANGE tests, written red first: an `unset` of a key no layer holds refused
  by a reader that never asks it, one shape over another above the leaves
  refused the same way, an array of tables over a list of values and the
  reverse refused, the empty list under and over either appended.
- CHANGE `renki-config`: `Meta::defect` refuses a non-string item of
  `include`, `replace` or `unset` by name; `glob_matches` matches no `.` that
  begins a name; the predicate table is checked whole when read, a malformed
  definition refused whether it is used or not.
- CHANGE `renki-manifest`: the owning `Room<TEXT, NODES>` is removed;
  `Host::read` opens with `O_NONBLOCK` and refuses what `fstat` says is no
  regular file with `BadRead::NotAFile`; `Host::list` clears `errno` before
  each `readdir` and refuses a listing that ends in an error; `Host::var`
  copies the value into memory the caller gives; the shell's wrapper sends
  standard output to `/dev/null` and exits 125 where `cd` fails. Tests: a
  directory, a FIFO and a file that grows past what `fstat` said.
- CHANGE `renki-manifest`'s package: the readme it names exists, and its
  categories carry `no-std`; the root readme names every crate and `posix/`.
- CHANGE the POSIX reader: a directory entry naming no directory refused;
  every layer found placed by the order and checked as untracked, read or
  not; a non-string item of `include`, `replace` or `unset` refused; the
  predicate table checked whole when read; `..` and links resolved by
  `cd -P`; a newline in a path refused; no leading `.` matched by a glob; a
  control byte in a string or a comment and bytes that are no UTF-8 refused;
  the shell's `cd` failing exits 125; the header says a shell predicate runs
  on every read; `canon` and `debug` share one walk.
- CHANGE the suite: invalid fixtures kept as `.toml.in` and copied to their
  names; a fixture for every refusal of either reader and for each of the
  eight decisions; paths with a space or a quote, an include through a link,
  a dot file beside a glob and git failing to answer; a committed broken copy
  of the POSIX reader that turns the suite red.
- CHANGE `renki-manifest`'s readme, the one its package names, with a test
  holding its tagline to the package's description, the version it installs
  to the one shipped, and its usage block's imports to the crate's exports.
- CHANGE the POSIX reader keeps the four points decided at the fifth
  reopening: a non-layer a glob matches refused, a directory among them; an
