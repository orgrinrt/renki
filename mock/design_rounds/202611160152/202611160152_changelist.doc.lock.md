# doc changelist

Descends from `202611160152_topic.one-copy-of-every-built-engine.md`, the only
open topic, which this changelist consumes whole.

## What lands

- `mock/crates/renki/DESIGN.md.tmpl`, "One build per key": the key's target
  directory is no longer kept. The intermediates go to the build directory the
  repository's cargo configuration names, read by `build_dir` and carried as
  `CargoPlan::build_dir` into `CARGO_BUILD_BUILD_DIR`; a finished install
  removes the key's target; a key with its binary and a leftover target has the
  target removed under its lock; the scratch build and the reinstall follow the
  same rule.
- The same section: a build no repository resolves to is removed when the run
  that left it is recorded, not on the daily pass.
- `mock/crates/renki/README.md`, the cache paragraph: only the binary stays,
  and an unpinned build goes on the next run.

## Claims the source changelist will carry

- CHANGE `CargoPlan` gains `build_dir: Option<PathBuf>`, set in the environment
  of every attempt as `CARGO_BUILD_BUILD_DIR`.
- CHANGE a finished `Cargo` install removes `CargoPlan::target_dir`.
- CHANGE a new module `build_dir` resolves the build directory from a
  repository root; `ensure_built`, `engine::build` and the reinstall use it.
- CHANGE `ensure_built` removes a leftover target of a built key under the
  key's lock.
- CHANGE `Registry::record` is followed on every run by the removal of builds
  no consumer resolves to; `gc` keeps the retention pass.
- CHANGE `renki` 0.0.5-rc.2.
