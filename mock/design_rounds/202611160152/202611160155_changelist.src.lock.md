# src changelist

The source that the locked doc changelist `202611160152_changelist.doc.lock.md` describes, and the tests for it. Descends from the topic file `202611160152_topic.one-copy-of-every-built-engine.md`.

## What lands

- `mock/crates/renki/src/build_dir.rs`, new: `build_dir(root)` reads cargo's configuration as a build in `root` would, the variables, each `.cargo/config.toml` from `root` upward and `$CARGO_HOME`'s, taking `build.build-dir` or else the target directory. `resolve` is the same on its inputs. Tests in `build_dir_tests.rs`.
- `mock/crates/renki/src/extension/cargo.rs`: `CargoPlan::build_dir`, given to every attempt as `CARGO_BUILD_BUILD_DIR`; a finished install removes `CargoPlan::target_dir` through `drop_target`.
- `mock/crates/renki/src/cache.rs`: `build_plan` sets `build_dir` from the build's directory; `ensure_built` removes a built key's leftover target under the key's lock (`drop_leftover_target`).
- `mock/crates/renki/src/engine.rs`: the `--engine` scratch plan sets `build_dir` from the repository's root.
- `mock/crates/renki/src/selfupdate.rs`: the reinstall gets the build directory of where the launcher runs and removes its target once done.
- `mock/crates/renki/src/registry.rs`: `Registry::evict` is the one removal body; `gc` keeps the retention rule through it and `drop_unresolved` removes builds no consumer resolves to. `record_and_collect` runs `drop_unresolved` on every run.
- The `0.0.5-rc.2` the doc changelist names is not here: the readme's install line has to move with the manifest, and the readme is frozen in this window, so the bump is a round of its own straight after this one.
- Tests: `an_install_with_a_build_dir_compiles_there_and_leaves_no_target_under_the_cache_root`, `an_install_with_no_build_dir_removes_its_private_target` and `a_built_key_loses_the_target_an_earlier_launcher_left` in `cache_tests/one_copy.rs`, which run a real offline `cargo install` of a fixture crate; `installing_two_pins_in_turn_leaves_one_binary` and `a_build_another_repository_still_resolves_to_is_kept` in `registry_tests/superseded.rs`. All but the last were committed red before the source.
- `mock/lints/the_placement_branch_exists_once.rs`: `all_sources` is a method on the pinned lint context, landed with the doc window since the lint did not build.

## Claims

- After `ensure_built` installs a key, no directory named `target` is under the cache root, with a build directory configured and without one.
- With `build.build-dir` set in the repository's `.cargo/config.toml`, the install's intermediates are in that directory.
- `record_and_collect` leaves one build for a repository that resolved two keys in turn within the same day, and keeps a key another repository still resolves to.
- `the_unix_assumption_is_stated` fails on this machine for want of the `wasm32-unknown-unknown` target, as it does on `dev`; nothing here touches it.
