# doc changelist

One paragraph in renki's design, and the document rendered from it. Descends
from the topic file `202609181727_topic.a-credential-helper-and-the-untested-edges.md`.

## What lands

- `mock/crates/renki/DESIGN.md.tmpl`, "Asking a remote for a branch head": git
  does not prompt on the terminal, and a credential helper is told not to open a
  window, which Git Credential Manager honours and a helper ignoring the setting
  does not; a stored credential is still used. The deadline holds over the
  answer and not over a prompt or a window, since only git is killed.
- `docs/`, rendered.

## Claims the source changelist will carry

- `ask::quiet_git` passes `-c credential.interactive=never` ahead of whatever
  the caller adds, so the one call carries it and no configuration is written.
- `ThisProcess` is tested by running the test binary again as a child in a
  clone the test sets up, with `GIT_SSH_COMMAND` and `GIT_SSH` as the test
  states them and the global and system configuration cleared: it reads both
  variables and the clone's `core.sshCommand`, and `quiet_git` over it sets
  `BatchMode` only in a clone that says nothing.
- `pin::ls_remote_head`, the wrapper both callers reach, answers a branch head
  from a local repository through `ThisProcess`, and an error for a branch the
  repository does not have.
- The stdin test runs in a child of the test binary whose stdin is a pipe the
  parent holds open until the child is done, so a child that inherited stdin
  would wait for the deadline instead of reading end of file.
- Each new test is shown failing with its fix taken out.
