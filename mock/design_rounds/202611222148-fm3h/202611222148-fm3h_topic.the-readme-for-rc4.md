# the-readme-for-rc4

The published prose ahead of `0.0.5-rc.4`. The crate readme pins `0.0.5-rc.3` in its usage block, which goes stale the moment rc.4 ships, and it says nothing about what rc.4 changes for a launcher's user: a branch, revision or tag pin that moved now builds from its own sources, where before a shared build directory could hand it the engine of the revision it replaced. The pin moves to rc.4 and one sentence under where it keeps things says that. The root readme, the other two crates' readmes, the rustdoc and the `Cargo.toml` descriptions name no version and nothing in them is stale against `dev`.
