# the-install-lines-name-the-released-versions

The release round for `0.0.3`, and the first release of `renki-dirs` and
`renki-config`, at `0.0.1` each. Each crate's readme carries an install line
naming the version the manifest ships, pinned by the readme truth test in
every crate, so a bump of the three manifests is a bump of the three install
lines with it, and the two smaller crates' readmes are doc templates to the
gate, which is why a round opens for what is otherwise a version number.

Nothing else in the prose changes. The root readme's line moves with the
manifest outside the gate, the changelog is a new root file the gate does not
read, and the rendered `docs/STRUCTURE.md` follows the two readmes when the
documents regenerate.
