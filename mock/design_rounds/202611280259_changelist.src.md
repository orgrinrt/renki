## Claims

- CHANGE `renki-config`: `BadLayer::NotAWord` and `BadLayer::NotAString`,
  each with its `MetaList` and its `Got`, in place of `BadLayer::OrderItem`;
  `Meta::defect` refuses `meta`, `meta.overlays` and `meta.predicates`
  holding no table as of the wrong shape, in every layer, and an item of
  `meta.overlays.untracked` that is no word.
- CHANGE `renki-config`: `BadPredicate::Value` writes the value as the dump's
  basic string; `Predicates::read` refuses a loop through the walk `holds`
  answers by, which there names no variable and runs nothing; a command's
  exit above 128 is no exit.
- CHANGE `renki-manifest`: `BadRead::Os` and `BadRead::NotAFile` write the
  file unquoted, the first neither the call nor `errno`; `BadRead::NotText`
  is gone; `renki-config`, `tomlfuse-parse` and `serde` leave the
  dependencies, the first two staying the tests'; the tests take
  `processes` in a plain test run.
- CHANGE `renki`: `Toml::shape` answers an inline array as `Tables` only where
  every item is an inline table.
- CHANGE `posix/manifest.sh`: every refusal in the design's words, the
  parser's for a document that is no TOML, at the line the parser names;
  the merge refusal at the higher layer's key naming both shapes; a loop
  refused when the table is read; `/bin/sh` for a predicate, its status read
  from the shell that waits on it; files read through `tr`, so no `awk` holds
  a NUL byte; byte classes built from the bytes; `canonical` free of `ls`'s
  quoting.
- CHANGE tests, red first: `every_refusal_is_one_line_of_the_design`, holding
  every `Display` to the designs' tables, every fixture's refusal to one line
  of them and every line but those held elsewhere to a fixture; the suite
  under `dash` and `bash` and every installed `awk` of four, no `env`
  predicate naming a variable a shell reads; fixtures for a base that is no
  `name.ext`, a directory and an include that cannot be listed, a layer found
  that then cannot be read, `/bin/sh` whatever the path holds, `meta.predicates`
  of the wrong shape in an overlay, a loop nothing uses and an empty list in a
  merge refusal; a listing that ends in an error; an inline array of mixed
  items.
