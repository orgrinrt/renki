# the-units-reexport-the-tests-read

The test build of `renki` does not compile on `dev` at 15b1dd2. `cache_tests/a_new_revision.rs` calls `crate::extension::path_units` and `crate::extension::forget_units`, and both functions are `pub(crate)` in `extension/cargo.rs`, which `extension.rs` declares as a private module and re-exports from only `install_args`, `drop_target`, `set_build_dir`, `Cargo` and `CargoPlan`. `cargo test` in `mock` says `E0425: cannot find function path_units in module crate::extension`, twice, so the release gate's test step cannot pass on the tip.

The locked source changelist of round 202611191642 already claims the re-export: "`extension.rs`: `forget_units` and `path_units` re-exported to the crate". The line never reached the commit. This round adds it and nothing else, so that the tip builds its tests and 0.0.5-rc.4 can be gated.

Op was away when this was decided (22 November, the overnight blessing in the job brief), and the call is derived from the earlier round's own claim, with no alternative open: the two functions are used only by `Cargo::build_with` and by those tests, so a crate-level re-export is the smallest surface that fits.
