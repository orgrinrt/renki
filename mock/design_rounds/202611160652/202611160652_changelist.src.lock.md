# src changelist

The source that the locked doc changelist `202611160651_changelist.doc.lock.md` describes, and its tests. Descends from the topic file `202611160650_topic.one-build-per-pin-whatever-the-caller.md`.

## What lands

- `mock/crates/renki/src/cache.rs`: `CALLER_TOOLCHAIN_VARS`, `in_selected_toolchain`, and `fingerprint_of`, which `rustc_fingerprint` is with `rustc`.
- `mock/crates/renki/src/extension/cargo.rs`: `Cargo::build_with` runs each attempt through `in_selected_toolchain`.
- `mock/crates/renki/src/pin.rs`: `resolve_branch` asks the remote first and falls back to the recorded resolution; `BRANCH_TTL` and `fresh_resolution` removed.
- `mock/crates/renki/src/tool.rs`: the defect for a `cache_retention` under the hour removed, and its case in `lib_tests.rs`.
- Tests: `the_key_reads_the_same_toolchain_whatever_toolchain_the_caller_picked` and `an_install_under_a_callers_toolchain_builds_with_the_one_the_key_read` in `cache_tests/one_copy.rs`; `a_branch_pin_sees_the_remote_move_on_the_next_run_and_keys_the_same_build_when_it_did_not` in `pin_tests.rs`, which replaces the test of the hour's window.

## Claims

- Without the removal of `CALLER_TOOLCHAIN_VARS`, both toolchain tests fail: the key answered nothing under the caller's toolchain, and the install stopped on `override toolchain 'renki-no-such-toolchain' is not installed`. Run once that way here, then put back.
