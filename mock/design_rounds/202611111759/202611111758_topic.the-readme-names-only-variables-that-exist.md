# the-readme-names-only-variables-that-exist

The readme truth test of `renki`, `the_variables_the_readme_names_are_the_ones_a_launcher_reads`, fails on `dev`
since the readme was rewritten. It collects every backticked `WIDGET_` name the
readme prints and compares the set with the variables a tool called `widget`
answers to. The sentence on the engine's per-setting variables prints the bare
prefix `WIDGET_CFG_` in backticks as well as the real name
`WIDGET_CFG_MODEL_BASE`, so the readme names a variable that no tool answers
to.

The sentence is reworded to say one variable per setting and give the real
example, which is as much as a reader needs, and the prefix stays readable
from the example. Nothing else in the readme moves. The round is part of the
release candidate `0.0.5-rc.1`, since a published readme that its own test
refuses is the kind of leftover the prose check is for.
