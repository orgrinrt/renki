# src changelist

The source half of the fix round: the four findings the review made in the
source, each fixed at its site with the test that would have caught it, and
the split the file-size lint asked for on the way. Descends from the locked
doc changelist `202609041527_changelist.doc.lock.md`.

## CHANGE: `Tool::defect` FROM `refuses a command named after the crate's queries` TO `refuses one named after its flags too: dir_flag, engine_flag, and --cfg on a tool with settings`
File: `mock/crates/renki/src/tool.rs`, `mock/crates/renki/src/tool_tests.rs`
Verification: `grep -c 'const_str_eq(name, self.dir_flag)\|const_str_eq(name, self.engine_flag)\|const_str_eq(name, Cli::CFG_FLAG)' mock/crates/renki/src/tool.rs` is 3; `cargo test -p renki a_command_named_after_a_launcher_flag` is green over four refused arms, one of them a renamed flag, and two controls, every one of them also a `const _: () = assert!(...)`.

## CHANGE: `Cli` FROM `names the directory and engine flags` TO `names --cfg too, and the reader uses it`
File: `mock/crates/renki/src/tool.rs`, `mock/crates/renki/src/config/mod.rs`
Verification: `grep -n 'pub const CFG_FLAG' mock/crates/renki/src/tool.rs` returns one match; `grep -c '"--cfg"' mock/crates/renki/src/config/mod.rs` is 0 in the reader's match arms, the diagnostics keeping the spelling; `cargo test -p renki the_cfg_flag_comes_off` is green.

## CHANGE: `Invocation` FROM `five public fields, in tool.rs` TO `private fields, accessors and a crate-private constructor, in command.rs beside Command`
File: `mock/crates/renki/src/command.rs`, `mock/crates/renki/src/tool.rs`, `mock/crates/renki/src/lib.rs`, `mock/crates/renki/src/lib_tests/commands.rs`
Verification: `grep -c 'pub ' mock/crates/renki/src/command.rs` counts the two structs, the three public fields of `Command`, and the six accessors of `Invocation`, with `grep -n 'pub(crate) const fn new' mock/crates/renki/src/command.rs` returning one match and `grep -n 'pub struct Invocation\|pub struct Command' mock/crates/renki/src/tool.rs` none; `cargo mock --lint-only` reports no `file-size` finding on `tool.rs`; `cargo test -p renki tests::commands::` is green, with `record` reading through every accessor.
