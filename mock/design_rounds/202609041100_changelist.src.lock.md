# src changelist

The source half of the round the doc changelist beside this opened: the
repository takes mockspace, `renki-config` lands as the contracts crate, and
the launcher implements them for TOML, resolves every setting once, answers
`widget config`, and retries a failed install once after checking for cargo.

## CHANGE: the crates FROM `./` and `./renki-dirs` TO `mock/crates/<name>`
File: `Cargo.toml`, `mock/crates/renki/Cargo.toml`, `mock/crates/renki-dirs/Cargo.toml`
Verification: `grep 'members = \["mock/crates/\*"\]' Cargo.toml` returns one match, and `cargo metadata --format-version 1 --no-deps | grep -o '"name":"renki[a-z-]*"' | sort -u` lists `renki`, `renki-config` and `renki-dirs`.

## CHANGE: crate `renki-config` FROM `absent` TO `no_std contracts: Kind, Scope, Setting, Declared, Store, Literal, resolve`
File: `mock/crates/renki-config/src/{lib,kind,scope,setting,store,literal,resolve}.rs`
Verification: `grep -c '^#!\[no_std\]' mock/crates/renki-config/src/lib.rs` returns 1; `grep -n 'pub trait Kind\|pub trait Scope\|pub trait Store\|pub fn resolve' mock/crates/renki-config/src/*.rs` returns four matches; `cargo test -p renki-config` is green with the toy store suite.

## CHANGE: `Tool` FROM `no settings` TO `settings: &'static [Declared<Toml>]`
File: `mock/crates/renki/src/tool.rs`
Verification: `grep -n 'pub settings:' mock/crates/renki/src/tool.rs` returns one match, and `Tool::CONVENTIONS` carries `settings: &[]`.

## CHANGE: the TOML store FROM `absent` TO `impl Store for Toml over toml_edit, with a line-based writer`
File: `mock/crates/renki/src/config/toml.rs`
Verification: `grep -n 'impl Store for Toml' mock/crates/renki/src/config/toml.rs` returns one match; `cargo test -p renki config::toml` is green, including the round trip and the comment-keeping writes.

## CHANGE: the run FROM `no configuration` TO `settings resolved once and handed to the engine as <SHORT>_CFG_<KEY> and <SHORT>_CONFIG_FILE`
File: `mock/crates/renki/src/lib.rs`, `mock/crates/renki/src/config/mod.rs`, `mock/crates/renki/src/cache.rs`
Verification: `grep -n 'config::resolve_all\|config::engine_env' mock/crates/renki/src/lib.rs` returns two matches; `grep -n 'envs: &\[(String, OsString)\]' mock/crates/renki/src/cache.rs` returns one; `cargo test -p renki config::tests` is green.

## CHANGE: the `config` query FROM `absent` TO `path, schema, get, set, edit, answered before the engine`
File: `mock/crates/renki/src/config/query.rs`, `mock/crates/renki/src/lib.rs`
Verification: `grep -n 'is_the_config_query' mock/crates/renki/src/lib.rs` returns one match, placed before `discover::repo_root(tool).ok_or_else`.

## CHANGE: `Cargo::materialise` FROM `one attempt per plan entry` TO `a prerequisite check, then each attempt tried twice`
File: `mock/crates/renki/src/retry.rs`, `mock/crates/renki/src/extension.rs`
Verification: `grep -n 'install_with_retry\|cargo_is_on_path' mock/crates/renki/src/extension.rs` returns matches inside `materialise`; `cargo test -p renki retry::` is green.

## CHANGE: the launcher's rustdoc FROM `inline emphasis` TO `none`
File: `mock/crates/renki/src/{lib,cache,discover,env,extension,pin,selfupdate,tool,tool_tests}.rs`
Verification: `cargo mock --lint-only --strict` reports no `writing-style` finding.

## CHANGE: the borrowed strings and plain integers of the two no_std crates FROM `unmarked` TO `each site marked lint:allow with a reason and a FIXME naming the port`
File: `mock/crates/renki-dirs/src/lib.rs`, `mock/crates/renki-config/src/*.rs`
Verification: `grep -c 'FIXME: port to' mock/crates/renki-config/src/*.rs mock/crates/renki-dirs/src/lib.rs` is non-zero per file, and `cargo mock --lint-only --strict` reports no `no-bare-string`, `no-bare-numeric`, `no-bare-static-str` or `arvo-types-only` finding.

## CHANGE: the two oversize test files FROM `one file each` TO `a parent and children under 500 lines`
