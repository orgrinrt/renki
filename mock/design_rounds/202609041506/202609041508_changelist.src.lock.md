# src changelist

The source half of the round: the command table on the descriptor, the
dispatch that tries it, the resolved row made public for it, and the tests.
Descends from the locked doc changelist `202609041506_changelist.doc.lock.md`.

## CHANGE: `Tool` FROM `answers locate and config and forwards everything else` TO `carries a `commands` table of `Command`, tried after those two and before a root is required`
File: `mock/crates/renki/src/tool.rs`, `mock/crates/renki/src/lib.rs`
Verification: `grep -n 'pub commands:' mock/crates/renki/src/tool.rs` returns one match inside `Tool`, and `grep -n 'commands:        &\[\]' mock/crates/renki/src/tool.rs` one inside `CONVENTIONS`; `grep -n 'pub struct Command\|pub struct Invocation' mock/crates/renki/src/tool.rs` returns two; `grep -n 'fn run_command\|tool.command_named(args)' mock/crates/renki/src/lib.rs` returns one of each, the second between the `config` query and `no_root`; `grep -n 'Command,\|Invocation,' mock/crates/renki/src/lib.rs` shows both exported.

## CHANGE: `Tool::defect` FROM `does not read the command table` TO `refuses an empty name, a name locate or config takes first, and two commands of one name, const`
File: `mock/crates/renki/src/tool.rs`, `mock/crates/renki/src/tool_tests.rs`
Verification: `grep -n 'const fn commands_defect' mock/crates/renki/src/tool.rs` returns one match and `grep -n 'self.commands_defect()' mock/crates/renki/src/tool.rs` one inside `defect`; `cargo test -p renki a_command_table` is green over three tests, the refusals, the controls including the const assertion, and `command_named`.

## CHANGE: `config::Setting` FROM `pub(crate), fields public inside the crate` TO `pub ResolvedSetting with key, text and source accessors, fields private`
File: `mock/crates/renki/src/config/mod.rs`, `mock/crates/renki/src/config/query.rs`
Verification: `grep -c 'pub struct ResolvedSetting' mock/crates/renki/src/config/mod.rs` is 1 and `grep -c 'pub(crate) struct Setting' mock/crates/renki/src/config/mod.rs` is 0; `grep -n 'pub const fn key\|pub fn text\|pub const fn source' mock/crates/renki/src/config/mod.rs` returns three.

## CHANGE: the dispatch tests FROM `locate, config and the pins` TO `a command through outcome, one with no root, a refusal, and the order against the crate's queries`
File: `mock/crates/renki/src/lib_tests/commands.rs`, `mock/crates/renki/src/lib_tests.rs`
Verification: `cargo test -p renki tests::commands::` is green over four tests; the first asserts the flag ahead of the name and the flag after it both resolve and neither reaches the command, the second calls `run_command` with `None` for the root, the third has the command's own string come back as the launcher's error, and the fourth has `config get` answer with a command table present and the command not run.

## Not changed, and why

`Hooks` gains nothing: a command is not a hook, it runs only when named, and
the topic file says why it is a table on the descriptor rather than a field
there. `config::query::SUBCOMMAND` stays `pub(crate)`, read by the defect
check through the crate. The root readme is hand-written and carries its
paragraph from the doc changelist; the eight-line `README.md.tmpl` says
nothing about queries and is left alone.
