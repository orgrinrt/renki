# review-of-one-copy-of-every-built-engine


The review of round 202611160152 found seven things, each taken here.

A templated build directory was handed to cargo verbatim, and cargo expands `{workspace-root}` and `{workspace-path-hash}` against the workspace of the package being installed, a checkout per revision, so every key would get a build directory of its own for good. `{workspace-root}` is expanded against the repository's root, which is the workspace the template was written for, and a value carrying `{workspace-path-hash}` gives no build directory at all, since no hash cargo would compute for the install names the repository's.

Removing a build no repository resolves to on every run made a race real: the registry is loaded, changed and saved with no lock, so two launchers interleave and one saves over what the other recorded. The whole of loading, recording, collecting and saving is held under one lock on a file beside the registry.

The launcher's reinstall now removes its target, which every reinstall on the machine shares, so the first to finish removed the directory the second was compiling into. The reinstall is held under one lock for the machine.

A comment in `lib.rs` still says builds are collected at most once a day.

The design and the plan's field said the install compiles nothing the repository already built. `cargo install` does not read the repository's `[patch]`, its flags or its profile overrides, so it shares only the units that come out the same. Said so.

Cargo reads `.cargo/config` over `.cargo/config.toml` where both are there, and refuses a file that does not parse. The reading here matches both: the extensionless file first, and a file that does not parse is an error the build reports, not a level skipped.

Missing tests: the precedence of the target directory's variables and file, a variable's target directory against a file's build directory, a cargo home among the root's ancestors, the removal of the scratch build's and the reinstall's targets, and a key whose lock is held surviving the removal of unresolved builds.
