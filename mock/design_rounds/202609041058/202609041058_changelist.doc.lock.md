# doc changelist

The design documents for the three crates, written for the first time, since
the repository had none before it took mockspace. They descend from the
workspace design `.shared/designs/renki-configuration.md` and from the topic
file beside this changelist.

## What lands

- `mock/crates/renki/README.md.tmpl` and `DESIGN.md.tmpl`: the launcher
  library as it ships, naming every public item the root readme does not, and
  the two new surfaces this round adds to it: the configuration reader, writer
  and `config` query, and the retried install with its prerequisite check.
- `mock/crates/renki-dirs/README.md.tmpl` and `DESIGN.md.tmpl`: the table of
  roots, every type in it, and the decision that its strings are borrowed from
  the caller's text.
- `mock/crates/renki-config/README.md.tmpl` and `DESIGN.md.tmpl`: the
  contracts, which is the design of this round. Kinds and scopes as marker
  types, the typed setting and its erased row, the store contract and the
  resolver over any store, the precedence and the provenance, and the
  boundary between what the contracts own and what a launcher implements.

## Claims the source changelist will carry

The `renki-config` crate does not exist yet, so every type its design names is
a claim about the source changelist that follows. The design says what each
is; the source changelist says where each lands and how that is checked.
