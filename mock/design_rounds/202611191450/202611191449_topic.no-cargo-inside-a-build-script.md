# no-cargo-inside-a-build-script


A build script calls a tool that is a renki launcher. The launcher finds no engine for its key, or finds its hourly self-update due, and runs `cargo install`. Since 0.0.5-rc.2 that install compiles in the consuming repository's build directory, the same one the build running the build script holds, and cargo takes `<build dir>/<profile>/.cargo-build-lock` for the whole of a build. The install waits on the lock, the build waits on its build script, and the build script waits on the install. Seen four times in one day in one workspace, each time for 20 to 85 minutes at no load until the chain was killed by hand; the tool was `homma local show`, reached from a shader build script.

The sketch `mock/research/sketches/202611191450_cargo-holds-its-build-lock/` measured which of cargo's runs hold the lock and how a program can tell which run it is under. A build script runs with every lock held; the program of a `cargo run` and a `cargo test` binary run with every lock free. A build script alone has `TARGET` and `HOST` set, beside the `CARGO` and `OUT_DIR` the other two also have.

So a launcher that sees all four of `CARGO`, `OUT_DIR`, `TARGET` and `HOST` set runs no cargo at all. An engine already built for the key runs as it is. A key with no engine fails at once, without taking or waiting on the key's lock, since a launcher outside the build holding that lock may itself be waiting on the build directory's lock: the message says the run is a build script's and names the command that builds it from a shell. The self-update is skipped for that run, as it is under the opt-out variable. The `--engine` scratch build is refused the same way, since it is a `cargo install` too.

Weighed and not taken: a build directory of the launcher's own for an install under a build script, which would compile every dependency of the engine a second time and keep that copy; and a timeout on the wait, which would turn a deadlock into a failure some minutes later and give a legitimately long build the same failure.
