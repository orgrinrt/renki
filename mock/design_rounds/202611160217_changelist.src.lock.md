# src changelist

The source that the locked doc changelist `202611160217_changelist.doc.lock.md` describes, and its tests. Descends from the topic file `202611160216_topic.second-review-of-one-copy-of-every-built-engine.md`.

## What lands

- `mock/crates/renki/src/extension/cargo.rs`: `set_build_dir` gives every attempt `CARGO_BUILD_BUILD_DIR`, the build directory read or else the target directory; `Cargo::build_with` takes the command an attempt starts from, and `Cargo::build` is it with `cargo`.
- `mock/crates/renki/src/selfupdate.rs`: `Reinstall::run` sets the build directory the same way, takes `launcher.lock` with `try_take` and answers `Ok(false)` when another launcher holds it; `maybe_self_update` re-executes only on `Ok(true)`.
- Tests: `a_path_hash_in_the_cargo_homes_config_does_not_reach_the_install` and `a_path_hash_in_an_inherited_variable_does_not_reach_the_install` in `cache_tests/one_copy.rs`, the same two for the reinstall and `a_reinstall_another_launcher_holds_is_skipped_without_waiting` in `selfupdate_tests.rs`, which replaces the test that waited.

## Claims

- With `set_build_dir` setting the variable only where a build directory was read, the four path-hash tests fail: cargo built into the hashed directory from the cargo home's configuration and from the inherited variable. Run once that way here, then put back.
- `no-runtime-spawn` (`mockspace-extra-lints/src/lints/no_runtime_spawn.rs`) matches `thread::spawn` and its siblings as text on a line; the scoped `s.spawn(` in `registry_tests/superseded.rs` matches none, and the gate flagged only the two `std::thread::spawn` lines, so it carries no allow.
