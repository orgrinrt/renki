# release-0-0-5-rc-1

The release round for `0.0.5-rc.1` of `renki`. The launcher's self-update now
reinstalls the launcher into a target directory under the cache, so it no
longer leaves `cargo install` scratch directories under `/tmp`, and homma's
launcher is waiting on that fix. `0.0.4` on crates.io predates it.

The authority is the workspace rule that an agent may cut and publish a
release candidate, `x.y.z-rc.N`, whenever the work needs one, once the
published prose has been checked. A stable version waits on op, so this round
is a release candidate and nothing more.

Only `renki` moves. `renki-dirs` and `renki-config` changed in their readmes
since `0.0.4` and in no source or public name, so they stay at `0.0.2` and the
requirement `renki` names for each stays.

The published prose check found two kinds of leftover in the rustdoc of
`renki`. Eight doc comments carry bold, which the writing style forbids in
anything a reader sees, and the doc on the near-miss key check in `manifest.rs`
uses a key named after the workspace's own tooling as its example, where the
other lines of that comment use `widget_`. Both are put right here, as doc
comment text only: no item, signature or behaviour changes.

The install line in the readme of `renki` names the version the manifest ships,
so it moves with the manifest. The changelog gains the block for the release,
and `Cargo.lock` is regenerated by cargo.
