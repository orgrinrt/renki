# rustdoc-names-no-tool


The published prose ahead of `0.0.5-rc.4`, read again against what a stranger on docs.rs sees. Two doc comments use the names of tools that are not this repository's to name: the `user_file` comment in `renki` gives `~/.config/homma/homma.toml` as its example path, and the `Namespace` comment in `renki-dirs` lists `homma` and `vibecheck` as example directory names. Every other example in the readmes and the rustdoc uses `widget`. Both comments change to `widget`, which says the same thing and names nothing outside this repository. The readmes, the root readme and the `Cargo.toml` descriptions name no outside tool and are current against `dev`.
