# the-rendered-documents-name-no-round

A fix round, standing alone the way a defect found and fixed does. The
published prose gate ahead of the next release grepped the rendered
documents under `docs/` for what a stranger may not be shown, and found
three sentences in two design templates that describe the launcher and the
directory table as what a round added rather than as what the crate is. A
reader on the registry has no round to be inside, so the phrase names
nothing to them, and the rendered document is the public surface.

The three sentences say the same thing without the frame: the launcher's
design says what the readme leaves to the code and what the configuration
adds; the section is "Configuration"; and the directory table keeps the
borrowed form for now and marks every site for the port. Nothing else in the
templates changes and no source moves, so the source changelist says so and
exists so the round can close.
