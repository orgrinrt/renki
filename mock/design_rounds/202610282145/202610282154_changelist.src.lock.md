# src changelist

The source half of the round that clears the ten lint findings on the branch
`fix/one-engine-install-at-a-time`: six types renamed so no two crates define
one name, the two ignored tests tracked, the two spawns held behind one helper,
and the placement property moved from a test that read source text into a lint
of the repository's own. Descends from the doc changelist
`202610282145_changelist.doc.lock.md` and the topic file
`202610282145_topic.the-one-engine-install-branch-carries-ten-lint-findings.md`.

## CHANGE: `renki-dirs` public names FROM `Kind`, `Source` and the private `Sealed` TO `DirKind`, `PathSource` and `DirsSealed`
File: `mock/crates/renki-dirs/src/lib.rs`, `mock/crates/renki-dirs/tests/every_root_on_every_platform.rs`, `mock/crates/renki/src/cache.rs`
Verification: `grep -rnwE 'Kind|Source|Sealed' mock/crates/renki-dirs/src mock/crates/renki-dirs/tests` returns only the two prose words `Sealed` that open doc lines in `lib.rs`, and `grep -n 'renki_dirs::.*Kind' mock/crates/renki/src/cache.rs` names `DirKind`; `cargo test -p renki-dirs` is green.

## CHANGE: `renki-config` public names FROM `Source`, `Resolved` and the private `Sealed` TO `Origin`, `ResolvedView` and `ConfigSealed`
File: `mock/crates/renki-config/src/lib.rs`, `mock/crates/renki-config/src/resolve.rs`, `mock/crates/renki-config/src/scope.rs`, `mock/crates/renki-config/src/store.rs`, `mock/crates/renki-config/tests/every_contract_on_a_toy_store.rs`, `mock/crates/renki/src/config/mod.rs`, `mock/crates/renki/src/config/config_tests.rs`, `mock/crates/renki/src/lib_tests/commands.rs`
Verification: `grep -rnwE 'Source|Resolved|Sealed' mock/crates/renki-config/src mock/crates/renki-config/tests` returns nothing, and `grep -rnw 'Source' mock/crates/renki/src/config mock/crates/renki/src/lib_tests` returns nothing; `cargo test -p renki-config -p renki` is green. `renki`'s own `Source` in `extension.rs` and `Resolved` in `pin.rs` keep their names, and `cargo mock --lint-only --strict` reports no `single-source` finding, which is the measurement that nothing is left to pair.

## CHANGE: the two ignored tests in `retry.rs` FROM `a reason with no id` TO `a reason ending in "; tracked #30" and "; tracked #31"`
File: `mock/crates/renki/src/retry.rs`, `mock/crates/renki/LEDGER.md`, `mockspace.toml`
Verification: `grep -c 'tracked #3[01]"' mock/crates/renki/src/retry.rs` is 2; `mockspace.toml` carries `[lints.catalogue-ignore]` with `ledgers = "mock/crates/*/LEDGER.md"` and no severity key, and the two rows in the ledger resolve both ids; `cargo test -p renki retry:: -- --list --ignored` still lists both tests.

## CHANGE: the two lock tests in `cache_tests.rs` FROM `each spawning a thread` TO `both calling one helper that spawns it once, with the lint's allow and a reason`
File: `mock/crates/renki/src/cache_tests.rs`
Verification: `grep -c 'std::thread::spawn' mock/crates/renki/src/cache_tests.rs` is 1, on a line carrying `lint:allow(no-runtime-spawn) reason:`; `cargo test -p renki a_waiter_finds_the_binary_the_holder_built builds_of_different_keys_take_turns_on_the_shared_target_dir` is green, each still asserting that the waiter has not finished while the lock is held.

## CHANGE: the placement property FROM `a test that reads extension.rs with include_str` TO `the lint the-placement-branch-exists-once`
File: `mock/lints/the_placement_branch_exists_once.rs`, `mock/crates/renki/src/extension_tests/collecting.rs`
Verification: `grep -c 'include_str' mock/crates/renki/src/extension_tests/collecting.rs` is 0 and `nothing_but_place_decides_how_material_is_placed` is gone; `cargo mock lints` lists `the-placement-branch-exists-once` at `error`; `cargo mock test` runs its seven tests, among them the fixtures where the branch also sits in `locate` and where it is a `match`, both of which fail the lint, and the one where the only branch is outside `place`. On a copy of the tree with `if backend.places_itself()` added to `locate`, `cargo mock --lint-only --strict` reports `[the-placement-branch-exists-once] renki/src/extension.rs:592` naming lines 346 and 592; on this tree it reports no finding.

## Not changed, and why

`README.md` of `renki-dirs` keeps the word `Kind` as a column heading, a word
for the four directory kinds and not the trait. The root readme's `Resolved`
is `renki`'s own pin type. No lint severity moved anywhere: the only edit to
`mockspace.toml` is the ledger glob under a table that sets nothing else.
