# src changelist

The source that the locked doc changelist `202611051425_changelist.doc.lock.md` describes, and the tests for it. Descends from the topic file `202611051424_topic.review-fixes-for-forgetting-a-refused-build.md`.

## What lands

- `mock/crates/renki/src/pin.rs`: `forget_resolution` takes the refused revision as a third argument and removes the recorded resolution only while it still names that revision.
- `mock/crates/renki/src/lib.rs`: `message_forgetting_a_refusal` is the one place a failed build's error becomes text after a refusal has forgotten its resolution. `resolved_and_built` and the rebuild after an eviction in `dispatch` both go through it, and the comment that excused the rebuild is gone.
- `mock/crates/renki/src/extension.rs`: `place_via_scratch` is generic over the error and `place` no longer requires `Into<String>`, so the error type survives the scratch route.
- Tests: `a_cache_directory_that_cannot_be_made_is_a_build_that_never_started` and `a_build_lock_that_cannot_be_taken_is_a_build_that_never_started` in `cache_tests/typed_failure.rs`; `a_refusal_keeps_its_type_on_the_scratch_route` in `extension_tests.rs`; `a_refused_build_keeps_a_resolution_another_launcher_recorded_while_it_built` and `the_message_of_a_refused_rebuild_forgets_the_resolution_like_the_first_build_does` in `lib_tests/builds.rs`, whose key assertion now says it checks only the wiring.
- `mock/research/sketches/forget-resolution-mutants/`: the mutation record moved here with the doc phase, and its log gains the three mutants of this round.

## Claims

- `pin::forget_resolution(pin, cache_root, refused)` removes the record of the pin's url and branch only when it names `refused`, and removes nothing for a pin that names no branch.
- `lib::message_forgetting_a_refusal` forgets for a `Refused` and not for a `NotStarted`, and both `resolved_and_built` and `dispatch` call it.
- `extension::place::<E>` and `place_via_scratch::<E>` need only `E: From<String>`, and a `BuildError::Refused` going through either is still refused.
- `cache::ensure_built` answers `NotStarted` for a cache directory that cannot be made and for a build lock that cannot be taken. Shown red against a `From<String>` that answers `Refused`, a `forget_resolution` that does not check the revision, and a `message_forgetting_a_refusal` that never forgets, in `mutants.log`.
